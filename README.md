# Pitchroom — локальный запуск

Приложение работает на компьютере преподавателя и доступно студентам внутри одной локальной сети Wi‑Fi или Ethernet.

## Первый запуск

Установите Node.js 22 или новее, откройте Терминал в папке проекта и выполните:

```bash
npm install
npm run lan
```

После запуска в терминале появятся два адреса:

- `Local` — адрес для открытия на компьютере преподавателя;
- `Network` — адрес для студентов в той же сети, например `http://192.168.1.25:3000`.

Админ-панель находится по адресу `http://<IP-компьютера>:3000/admin`. Созданные в ней короткие ссылки автоматически используют сетевой адрес, с которого была открыта панель.

Не закрывайте Терминал во время занятия. Для остановки приложения нажмите `Control + C`.

## Данные

Группы, оценки и загруженные PDF хранятся локально в служебной папке `.wrangler`. Не удаляйте её, если хотите сохранить материалы между запусками.

Если macOS впервые спросит, разрешить ли входящие подключения для Node или workerd, нажмите «Разрешить».
